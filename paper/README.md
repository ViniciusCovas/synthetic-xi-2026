# Q1 Manuscript Results Package

This directory contains the frozen editorial package derived from Official Experiment v1.

## Core files

- `MASTER_RESULTS_REPORT_OFFICIAL_V1.md`: scientific source of truth for interpretation, claim hierarchy, robustness, and limitations.
- `RESULTS_SECTION_DRAFT.md`: manuscript-ready Results section in English.
- `FIGURE_CAPTIONS.md`: publication-ready captions.
- `PROVENANCE_MATRIX.md`: mapping from manuscript claims to frozen repository evidence.
- `figures/`: editable SVG figures.

## Editorial policy

- The 10,000-run experiment remains the primary confirmatory result.
- The 50,000-run experiment is an independent preregistered precision replication.
- The 60,000-run estimate is a secondary pooled precision summary only.
- Sensitivity and nested uncertainty must be reported prominently.
- These files do not modify the engine, rosters, parameters, hypotheses, seeds, authorization, or frozen results.
